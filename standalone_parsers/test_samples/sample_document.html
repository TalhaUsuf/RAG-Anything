RAG-Anything: Multimodal RAG Framework

Introduction

RAG-Anything is an all-in-one multimodal document processing and retrieval system. It processes documents containing diverse content types including text, images, tables, equations, and charts.

Supported File Types

Query Modes

  • Local - Vector similarity search
  • Global - Graph-based entity retrieval
  • Hybrid - Combined local + global
  • Mix - Blended approach (default)

Getting Started

Install RAG-Anything with pip: pip install raganything

Configure your LLM and embedding functions, then call process_document_complete() to begin.
